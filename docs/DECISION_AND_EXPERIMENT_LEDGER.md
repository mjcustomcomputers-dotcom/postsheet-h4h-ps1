# DECISION & EXPERIMENT PRESERVATION LEDGER (`H4H-PS1-SUBMISSION`)

- **Purpose:** Additive engineering and research ledger preserving **accepted**, **rejected-by-test**, **deferred**, **unchanged-preferable**, **superseded**, and **untested** methods across the Post Sheet | Ability & Purpose Crew Network repository (`b8626bf` -> `d3076df` -> `13fd030` -> Stage C/D Reactive Moonlight + `PSS-H4H-CRR-01.R1`).
- **Rule:** Nothing evaluated during design or verification is silently discarded. Every non-adopted or superseded mechanism records why it was set aside and what evidence would justify reconsidering it.

---

## 1. Classification Key

| Status Code | Meaning |
| --- | --- |
| `ACCEPTED` | Implemented, verified in build/browser/tests, and active in current `main` |
| `REJECTED_BY_TEST` | Tested or inspected against WCAG / UX / runtime invariants and rejected due to measured defect |
| `SUPERSEDED` | Worked in an earlier checkpoint (`b8626bf`, `d3076df`, or `13fd030`) and cleanly replaced by a higher-clarity iteration; preserved in Git history |
| `DEFERRED_SCOPE_OR_DEPS` | Valid design or engineering candidate withheld due to strict CSP, zero-dependency rules, or bounded Stage C/D scope |
| `UNCHANGED_PREFERABLE` | Existing implementation already satisfies optimality, safety, and test proofs; altering it adds risk without user benefit |
| `UNTESTED_PROPOSAL` | Research or experimental protocol documented for future human/lab validation; zero unverified empirical claims made |
